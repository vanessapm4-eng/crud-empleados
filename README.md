# CRUD Empleados

Sistema CRUD desarrollado para la gestión de empleados, permitiendo registrar, consultar, actualizar y eliminar información de empleados.

## Objetivo del proyecto
Aplicar conceptos de desarrollo backend y manejo de datos mediante la implementación de un sistema CRUD para la administración de empleados.

## Funcionalidades

- Registrar empleados  
- Consultar empleados  
- Actualizar información  
- Eliminar empleados  
- Gestión de datos

## Despliegue
- La aplicación se encuentra desplegada y disponible en: https://crud-empleadosvp.vercel.app/
- El Despliegue se realizó con: 
- Render para backend
- Vercel para frontend

## Tecnologías utilizadas

- JavaScript  
- Node.js  
- HTML  
- CSS

## Instalación y ejecución
- Clonar repositorio: git clone https://github.com/vanessapm4-eng/crud-empleados.git
-Entrar al proyecto: cd crud-empleados
- Instalar dependencias: npm install
_Ejecutar el proyecto: npm start
